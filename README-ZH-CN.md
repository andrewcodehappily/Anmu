# 暗幕 Anmu

[English](README.md) | [繁體中文](README-ZH-TW.md) | [简体中文](README-ZH-CN.md)

让指定 macOS App 的窗口变暗，保留原本的鼠标与键盘操作。

暗幕是一个轻量的菜单栏工具：在目标窗口上加一层可穿透的黑色半透明遮罩。只有指定 App 位于前台时才显示，切换到其他 App 就自动收起。

## 功能

- 从已打开的 App 列表选择目标。
- 调暗程度 0–95%，实时调整。
- 跟随目标窗口的位置与尺寸，每 0.15 秒更新。
- 支持加入 macOS 全屏空间；特殊游戏或独占全屏仍需单独测试。
- 遮罩不拦截鼠标、不获取键盘焦点；控制面板是普通窗口，不置顶。
- 全局快捷键 **Control＋Option＋Command＋D** 切换遮罩。
- 记住调暗程度与目标 App；每次启动默认关闭遮罩。
- 屏幕唤醒或显示器配置改变时，自动关闭遮罩。

## 系统要求

目前提供的编译脚本与下载版本适用于 **macOS 26.0 以上、Apple Silicon（arm64）**。这是当前的编译设置，不代表功能必须使用 macOS 26；尚未验证 Intel 或较旧 macOS。

## 下载与使用

从 [Releases](https://github.com/andrewcodehappily/Anmu/releases) 下载 ZIP，解压后打开 `暗幕.app`。目前为本地临时签名，未经 Apple 公证，macOS 可能限制打开；也可以自行审阅源代码并编译。

界面支持英文、繁体中文与简体中文，跟随 macOS 偏好语言；其他语言使用英文。更改语言后请重新打开暗幕，也支持 macOS 针对单个 App 的语言设置。

1. 打开要调暗的 App，再打开暗幕。
2. 从控制面板下拉列表选择目标；若找不到，点击“重新整理 App 清單”（刷新 App 列表）。
3. 调整“遮暗程度”，勾选“啟用遮罩”（启用遮罩）。
4. 点击“收起控制台，回到 App”（收起控制面板，返回 App）。
5. 通过菜单栏 **◐／●** 找回控制面板，或按全局快捷键切换遮罩。

要恢复原本亮度，可点击“立即恢復亮度”（立即恢复亮度）、关闭遮罩或退出暗幕。实体屏幕亮度需自行调整。

## 自行编译

安装 Xcode 或兼容的 Command Line Tools（需具备 macOS 26 SDK 与 Swift 编译器），在项目根目录执行：

```sh
./scripts/build.sh
open 'build/暗幕.app'
```

使用原生 AppKit、Core Graphics 与 Carbon，不需要第三方包。

## 限制

- 遮罩只是调暗画面，不会让 App 背景透明，也不保证旁人或 10 米外的人无法辨认内容。
- 多窗口 App 目前只处理列表中最前方、可见、尺寸大于 40×40 的普通窗口。
- 不进行屏幕录制或图像分析；使用系统窗口列表获取窗口位置与尺寸。
- 快捷键若注册失败，控制面板会显示提示，仍可使用菜单栏控制。
- 全屏、多显示器及不同 App 的兼容性仍需更多实测。编译成功不代表所有场景均已验证。
